同步与部署状态

每日 06:00（北京时间）由 daily_sync.yml 运行 sync_daily.py： 抓数 → 复用现有脚本回放模型 → feed.py 生成 data/ 接口 → 写入同源发布目录。 本页为静态文件，通过 fetch(..., {cache:"no-store"}) 读取最新接口，页面无需重建即可每日同步， 策略模型接口与看板页面数据始终同源。watchdog.yml 每 4 小时巡检，超 26 小时无新同步自动 workflow_dispatch 重启；deploy_pages.yml 把 index.html + data/ 发布到 GitHub Pages。
